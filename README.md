# Mondrian Art using CSS Grid

A recreation of a **Mondrian-style artwork** built using **HTML and CSS Grid**.

## Features

* Mondrian-inspired grid layout
* CSS Grid-based design
* Geometric shapes and sections
* Structured layout using rows and columns

## Technologies Used

* HTML
* CSS
* CSS Grid

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Purpose

This project was created to practice **CSS Grid, rows, columns, sizing, positioning, and layout design** by recreating a Mondrian-style artwork.
